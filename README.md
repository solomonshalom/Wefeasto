# Wefeasto
![image](https://user-images.githubusercontent.com/71135230/182664212-48df2883-056c-420c-956e-58a8790b1be4.png)
A simple yet effetive website made for wefeasto - A nutritional brand! In the making, I chose to go ahead with the classic techstack (HTML/CSS/JS) because their server couldn't support NodeJS or Bun (I know, no framework _Cries_). Though, working with it was also a blessing since it was easy to configure libraries and since, am also using CDN's, it worked pretty fast. The CSS in the site is a combination of Bootstrap and Plain'Ol CSS which turned out to be great since bootstrap did save a lot of development time (Even though I had to still write about 2000 lines of CSS :,)). 

# Notes
![image](https://user-images.githubusercontent.com/71135230/182664404-e5701670-3930-4acd-b819-8d55508a7836.png)
Most static files such as the ``script.js`` and ``style.css`` files inclduing some images are servered through a CDN for better performance. I am currently using JsDelivr which turned out to be a good decision as it was able to make the website much faster and the use of PartyTown made the load of the site's JS file's much lighter/faster.
